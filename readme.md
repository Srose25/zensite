# Project Title (Zensite)

This project is a website that is meant to help people who have trouble with focusing. The way it works is by creating a goal, and setting a timer. The timer allows you to have a deadline to get your goal accomplished. You will then be prompted a few questions after your session is over.

## Instructions for Build and Use

Steps to build and/or run the software:

1. You can click on the link to the website
or 2. create a live server of page-1.html

Instructions for using the software:

1. The ui is fairly simple to use
2. Any sections that don't require input can be skipped over by continuing.
